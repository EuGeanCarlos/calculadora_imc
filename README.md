# Calculadora de IMC — Thera

Atividade do Laboratório Thera/UEMA que calcula índice de massa corporal e apresenta classificação a partir de peso e altura.

## Tecnologias

- HTML
- CSS
- JavaScript

## Funcionalidades e utilização

Informe peso em kg e altura em metros e clique em Calcular IMC; por exemplo, 70 e 1,75 produzem aproximadamente 22,86.

## Como executar

```bash
git clone https://github.com/EuGeanCarlos/calculadora_imc.git
cd calculadora_imc
python -m http.server 8000 --directory "calculadora-imc"
```

Requer Python 3 para o servidor local. Abra http://localhost:8000.

# Calculadora IMC

## 📋 Descrição do Projeto
Este é um projeto de **Calculadora de Índice de Massa Corporal (IMC)** desenvolvido como atividade prática do Laboratório Thera da UEMA.  
A aplicação permite calcular o IMC de usuários com base no peso e altura fornecidos, classificando o resultado de acordo com os padrões estabelecidos pela **Organização Mundial da Saúde**.

## 🎯 Objetivo
**Objetivo Principal:** Desenvolver uma aplicação web funcional para cálculo do Índice de Massa Corporal, integrando conceitos de programação front-end aprendidos no Laboratório Thera.

## 🚀 Funcionalidades
- ✅ Cálculo automático do IMC  
- ✅ Classificação do resultado (Abaixo do peso, Normal, Sobrepeso, etc.)  
- ✅ Interface responsiva e intuitiva  
- ✅ Validação de dados de entrada  
- ✅ Exibição clara dos resultados  

## 🛠️ Tecnologias Utilizadas
- **HTML5** - Estrutura da página  
- **CSS3** - Estilização e design responsivo  
- **JavaScript** - Lógica de cálculo e interatividade
